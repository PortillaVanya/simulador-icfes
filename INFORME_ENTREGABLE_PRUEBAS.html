3. Automatización con Pipeline (CI) - GitHub Actions

Se configuró el pipeline de Integración Continua en el repositorio en la ruta .github/workflows/ci.yml. El pipeline se dispara ante cada push y pull_request hacia las ramas principales (main, master).

name: CI Pipeline - Simulador ICFES

on:
  push:
    branches: [ main, master ]
  pull_request:
    branches: [ main, master ]

jobs:
  test:
    name: Build & Test
    runs-on: ubuntu-latest

    strategy:
      matrix:
        node-version: [18.x, 20.x, 22.x]

    steps:
      - name: Checkout del código
        uses: actions/checkout@v4

      - name: Configurar Node.js ${{ matrix.node-version }}
        uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: 'npm'

      - name: Instalar dependencias
        run: npm ci || npm install

      - name: Ejecutar pruebas unitarias y de integración con cobertura
        run: npm run test:coverage
        env:
          NODE_ENV: test
          JWT_SECRET: test_jwt_secret_ci_environment_key_32chars

5. Flujo de Trabajo en Git y Pull Request

  1. Creación de rama individual de trabajo: 
    git checkout -b norman-pruebas
  2. Guardar y confirmar cambios localmente: 
    git add .
git commit -m "feat(tests): incorporar pruebas unitarias, integracion y pipeline CI"
  3. Publicar rama en el repositorio de GitHub: 
    git push -u origin norman-pruebas
  4. Apertura de Pull Request (PR): Ir a GitHub > Pull Requests > New pull request con origen norman-pruebas y destino main.
  5. Validación automática con CI: El flujo de GitHub Actions se ejecuta automáticamente. Todos los tests en las versiones 18.x, 20.x y 22.x se validan en verde.
  6. Aprobación e Integración: Revisión por pares y aprobación del PR para hacer el Merge en la rama main.
